# Wirdi Phone Test Package

هذا هو ملف المشروع الكامل لتجربة التطبيق على موبايل Android.

## الملف لا يحتوي على APK جاهز
لأن APK يحتاج Flutter SDK و Android SDK للبناء.

## يحتوي على
- كود Flutter كامل.
- إعدادات Splash و App Icon.
- GitHub Actions workflow لبناء APK تلقائيًا.
- دليل بناء APK محليًا.
